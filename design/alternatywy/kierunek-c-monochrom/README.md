# Kierunek C — monochrom (alternatywa, nieopublikowana)

Jedna z potencjalnych alternatyw wyglądu strony. Nie jest częścią `public/`, więc nie trafia na 40000steps.com.

- `index.html` — strona główna
- `telefon.html` — strona główna w szerokości telefonu
- `spacer.html` — zapis na spacer
- `img/` — zdjęcia w czerni i bieli (wariant „czerwony filtr”, delikatne ziarno)

Założenia: pełny monochrom, kroje Jost, układ jako przekrój plaży (niebo, morze, piasek, mgła, noc w stopce), główne akcje jako koła. Daty, miejsce spaceru i notatki to miejsca do uzupełnienia.

Pliki otwierają się bezpośrednio w przeglądarce.
